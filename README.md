# 🏠 House Price Prediction

A Machine Learning web application that predicts house prices based on property features such as bedrooms, bathrooms, stories, parking, location preferences, furnishing status, and other features.

## 🚀 Live Demo

The application is deployed using Streamlit.

**Live App:** [Open House Price Prediction App](PASTE_YOUR_STREAMLIT_LINK_HERE)

## 📌 Project Overview

This project uses Machine Learning to estimate the price of a house from user-provided property details.

The trained model is integrated into a Streamlit web application where users can enter property information and receive an estimated house price instantly.

## ✨ Features

- 🏠 House price prediction
- 📊 Machine Learning-based prediction
- 🖥️ Interactive Streamlit interface
- 📋 User-friendly input fields
- 💰 Price displayed in Indian Rupees

## ⚙️ How It Works

1. User enters house details in the Streamlit application.
2. The input data is preprocessed according to the model requirements.
3. The trained machine learning model receives the input.
4. The model predicts the estimated house price.
5. The predicted price is displayed to the user.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/manya-pri/HOUSE_PRICE_PREDICTION.git
cd HOUSE_PRICE_PREDICTION/APP
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit App

```bash
streamlit run app.py
```

### 4. Make a Prediction

Enter the required house details and click **Predict Price** to get the estimated house price.
